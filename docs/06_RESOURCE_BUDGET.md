# 06 Resource Budget v0.1

> M1 阶段为资源预算草案。M2 需要冻结 RAM、ROM、单次 `process()` 运行时间和功耗边界。

## 已确认约束

目标平台：Apollo3.5 / Cortex-M4F 级别，M2 冻结；允许 `float`；禁止动态内存；要求 MISRA 风格限制；逐点实时处理。

## 待确认默认假设

| 项目 | 当前默认假设 | 状态 |
|---|---|---|
| RAM | 10–15KB 级别 | 待 M2 冻结 |
| ROM | 未定 | 待 M2 冻结 |
| 单次 `process()` 时间 | 未定 | 待 M2 冻结 |
| 功耗 | 未定 | 待 M2 冻结 |

## RAM 初步分配思路

| 模块 | 初步预算方向 | 说明 |
|---|---:|---|
| Context / 状态机 | 小于 1KB | 状态、计数器、错误码 |
| 多通道短历史缓冲 | 主要预算项 | 仅保留算法所需窗口，不做大数组上栈 |
| 预处理状态 | 小于 2KB | IIR / 平滑状态优先 |
| SQI / 通道选择 | 小于 2KB | 只保留统计量与短历史 |
| 候选检测 | 小于 2KB | 峰值候选、上次 beat、IBI 历史 |
| debug / trace | 可选 | 如启用需单独预算 |

## 资源审查原则

不允许大数组定义在局部栈上；不允许动态内存；不允许为了 host 测试方便破坏 MCU 约束；若引入大窗口或复杂滤波，必须重新评估 RAM / ROM / 耗时；M8 必须进行资源预算审查与移植准备复盘。
